Runtime Boundary

The fetch script copies the official binary without modification. The engine is not linked into Flutter: Crazy Chess launches it and exchanges UCI text through standard input and output. The official GPL v3 license is included as COPYING.txt.

The versioned page provides an immutable source archive and SHA-256 checksum for Android 0.9.0+1 without requiring access to the private development repository.

Rebuilding Android 0.9.0+1

The release toolchain is Flutter 3.38.5 / Dart 3.10.4, JDK 17, Android Gradle Plugin 8.11.1, Gradle 8.14, Android compile/target SDK 36, minimum SDK 24, and NDK 28.2.13676358.

  1. Install Flutter and Android SDK 36 with NDK 28.2.13676358.
  2. Copy android/key.properties.example to the ignored android/key.properties and configure your own signing keystore. Never commit either secret file.
  3. Run ./scripts/fetch_stockfish_mobile_nnue.sh to download and verify the pinned NNUE files.
  4. Run make build-play-android.
  5. Optionally run make verify-play-android with bundletool available.

The resulting build/app/outputs/bundle/release/app-release.aab contains only arm64-v8a and armeabi-v7a Stockfish libraries.
