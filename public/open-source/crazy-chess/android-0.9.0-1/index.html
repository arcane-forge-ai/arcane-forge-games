Stockfish and license

Crazy Chess Android uses Stockfish 18 as an in-process native FFI chess engine. Stockfish is free software licensed under the GNU General Public License version 3 and is provided without warranty.

  • Upstream tag and commit: sf_18 / cb3d4ee
  • Vendored wrapper: stockfish 1.8.1+crazychess.1
  • Android ABIs: arm64-v8a, armeabi-v7a
  • Read the complete GPLv3 license text
  • Official Stockfish 18 release
  • Upstream Flutter wrapper 1.8.1

The Crazy Chess wrapper removes build-time downloads, requires prepared and hash-verified NNUE files, updates Android namespace/toolchain configuration, and exposes reliable asynchronous engine initialization and disposal. The archive contains the full vendored wrapper and Stockfish source, native build files, Dart integration source, license text, metadata, and reproducible preparation scripts.

Build information

The release toolchain is Flutter 3.38.5 / Dart 3.10.4, JDK 17, Android Gradle Plugin 8.11.1, Gradle 8.14, Android compile/target SDK 36, minimum SDK 24, and NDK 28.2.13676358.

  1. Install Flutter, JDK 17, Android SDK 36, and NDK 28.2.13676358.
  2. Unpack the source archive.
  3. Run ./scripts/fetch_stockfish_mobile_nnue.sh to download and verify the two pinned NNUE networks.
  4. Configure your own ignored android/key.properties and upload keystore.
  5. Run make build-play-android.

Additional provenance is available in SOURCE.md, SOURCE.html, and manifest.json.
